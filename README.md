Sistema de Estoque

Sistema web de controle de estoque desenvolvido em Python utilizando Flask e SQLAlchemy.

O sistema permite cadastrar categorias e produtos, registrar entradas e saídas de estoque, visualizar movimentações, receber alertas de estoque baixo e filtrar produtos por nome e categoria. Também possui endpoints de API que retornam dados em JSON.

Utiliza Python, Flask, Flask-SQLAlchemy, SQLite, HTML5, CSS3, JavaScript, JSON, Git e GitHub.

Para executar o projeto, utilize os comandos abaixo.

git clone https://github.com/vinnyzz07/sistema-de-estoque.git
cd sistema-de-estoque
python -m venv venv
pip install -r requirements.txt
python run.py

O sistema estará disponível em http://127.0.0.1:5000.

Projeto desenvolvido para praticar desenvolvimento web, operações CRUD, APIs REST e integração entre Python, banco de dados e frontend.
